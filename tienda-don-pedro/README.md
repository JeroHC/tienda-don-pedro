# Tienda Don Pedro

## ¿Quiénes somos?

La tienda Don Pedro es un pequeño negocio dedicado a la venta de productos de uso diario y alimentos para sus clientes.

Nuestro objetivo es ofrecer productos de manera organizada, llevar el control de los clientes, registrar las ventas fiadas y gestionar los domicilios.

## Productos y servicios

La tienda ofrece:

- Venta de productos de consumo diario.
- Registro de clientes.
- Control de productos.
- Servicio de domicilios.
- Registro de compras fiadas.

## Organización del proyecto

La carpeta del proyecto está organizada de la siguiente manera:

| Archivo | Descripción |
|---|---|
| `datos/clientes.txt` | Información de los clientes. |
| `datos/fiado.txt` | Registro de compras fiadas. |
| `datos/productos.txt` | Lista de productos y precios. |
| `datos/domicilios.txt` | Barrios y precios de domicilios. |
| `README.md` | Documentación del proyecto. |
